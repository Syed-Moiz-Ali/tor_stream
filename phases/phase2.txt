Continue from Phase 1.

Only implement Phase 2.

==================================================
OBJECTIVE
==================================================

Build a production-grade Torrent Session Manager.

This phase is ONLY responsible for communicating with the BitTorrent network.

No streaming.

No player.

No buffering.

No watch party.

==================================================
RESPONSIBILITIES
==================================================

The engine must:

• Initialize libtorrent
• Create torrent session
• Bootstrap DHT
• Discover peers
• Connect to trackers
• Handle magnet links
• Handle .torrent files
• Maintain torrent state
• Pause
• Resume
• Remove torrents
• Save fast resume data
• Restore previous session
