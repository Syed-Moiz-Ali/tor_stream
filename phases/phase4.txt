=========================================================
PROJECT GOAL
=========================================================

Build a production-grade Adaptive Torrent Streaming Engine.

This engine is the heart of the application.

The goal is to allow a user to start watching a movie before it has finished downloading.

The engine must stream directly from partially downloaded torrent pieces.

This engine must be designed for Android devices with limited RAM and storage while maintaining excellent playback performance.

=========================================================
PIECE SCHEDULER
=========================================================

The scheduler must dynamically assign priorities.

Priority order:

1. Current playback position
2. Read-ahead window
3. Near-future pieces
4. Remaining sequential pieces
5. Rare pieces when safe

Recalculate priorities whenever playback position changes.

=========================================================
SEEK SUPPORT
=========================================================

When the user seeks:

Cancel unnecessary requests.

Recalculate target pieces.

Immediately prioritize the destination region.

Resume buffering around the new playback position.

Seek operations should minimize waiting time.
